# Peggy Chen — Photography Portfolio

A responsive portfolio for Peggy Chen, built with plain HTML, CSS, and JavaScript. The gallery uses the original dog and pet-grooming photographs included in `asset/`.

## Preview locally

No build step or dependencies are required. From this folder, start a static file server, for example:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000> in a browser. You can also open `index.html` directly, though a local server is recommended.

## Files

- `index.html` — portfolio content and gallery
- `photo.css` — responsive layout, typography, and lightbox styles
- `script.js` — keyboard-operable photo viewer
- `asset/` — original photography
